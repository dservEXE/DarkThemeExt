# Night Sites для Brave

Версия 1.0.1: панель остаётся активной после переключения темы и яркости,
даже если другая вкладка долго загружается.

Тёмная тема для обычных HTTP/HTTPS сайтов на движке **Dark Reader**.
Нейтральные тёмные фоны, читаемый текст, сохранение цветов фотографий,
переключение без перезагрузки страницы и настройка яркости.

## Установка в Brave

1. Если скачали ZIP, распакуйте его в постоянную папку.
2. Откройте `brave://extensions/` в адресной строке Brave.
3. Включите **«Режим разработчика»** (Developer mode).
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку **`extension`**, где лежит `manifest.json`.
6. Откройте меню расширений Brave и закрепите **Night Sites · Тёмная тема**.
7. Нажмите значок луны и включите **«На всех сайтах»**.

Сборка и установка дополнительных программ не нужны. Сохраните папку `extension`
после установки: Brave загружает расширение из неё.

## Управление

- **На всех сайтах** — включает или выключает перекраску сразу для открытых вкладок.
  При первом запуске выключено, чтобы вы сами выбрали момент включения.
- **Текущий сайт** — позволяет оставить выбранный домен в исходных цветах.
  Исключение сохраняется для этого точного имени сайта и его вложенных фреймов.
- **Яркость темы** — от 70 до 110%; применяется после отпускания ползунка.
- **Сбросить** — возвращает яркость 100%.

Настройки сохраняются локально в профиле Brave и действуют после перезапуска.
ЛК ДГТУ: https://lk.donstu.ru/webapp/ — перекраска работает независимо
от переключателя темы, предусмотренного самим университетом.

## Доступ и данные

Brave запрашивает доступ к сайтам, поскольку расширение меняет их оформление.
Разрешение `storage` сохраняет настройки, `scripting` применяет тему к вкладкам,
которые уже были открыты при установке. Движок находится внутри пакета;
удалённый JavaScript не загружается.

Расширение не отправляет историю посещений, логины, пароли или содержимое страниц
на сервер разработчика. Для разбора оформления оно может повторно запрашивать
стили и изображения, указанные самой страницей. Запросы к ресурсам другого домена
через фоновый процесс выполняются без cookies.

## Ограничения

Браузер запрещает менять оформление служебных страниц (`brave://`, `chrome://`),
магазина расширений и встроенного просмотра PDF. Текст внутри фотографий,
видеозаписей и некоторых canvas-элементов остаётся частью изображения.
Если конкретный сайт перекрашивается неудачно, отключите тему для него
переключателем «Текущий сайт».

## Проверка и исходный код

Проверено в отдельном профиле установленного Brave: включение/выключение,
исключения, вложенные фреймы, стили с другого домена, динамические блоки,
яркость, сброс и сохранение темы после перезагрузки страницы.
Страница входа ДГТУ проверяется без авторизации; закрытые разделы не проверялись.
Отчёт и снимки находятся в папке `verification` исходного проекта.

`extension` — готовое расширение, `src/content.js` — контроллер темы,
`vendor` — оригинальный движок с данными о версии и контрольной сумме,
`tools/build.cjs` — воспроизводимая сборка.

Для повторной сборки достаточно Node.js: `node tools/build.cjs`.
При отсутствии исходника движка сначала выполните `node tools/vendor.cjs`.
Для функциональной проверки требуется Playwright и установленный Brave:
`node tools/check.cjs`. Путь к Brave можно задать через `BRAVE_PATH`.
